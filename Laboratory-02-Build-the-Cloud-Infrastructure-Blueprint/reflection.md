**Checkpoint 7**

I think networking is the most important element of cloud infrastructure since it is what links all the components together. It wouldn't be of any use having a great deal of computing power or storage capacity if the various systems were unable to communicate with one another or with the internet. Moreover, networking contributes to security as it determines who is allowed in and who isn't.

Linux is helpful in the field of cloud computing since it is free, lightweight, and easy to modify. At present, the majority of cloud servers run on Linux because it does not require expensive licenses and it performs well with a wide variety of programs. For this task, I used some simple commands such as free -h, df -h, and hostname to check the system, thereby seeing how cloud engineers make use of Linux every day when looking after servers.

It is important to have technical documentation when setting up an infrastructure since it allows all concerned parties to see what the system will be like before it is actually constructed. Should any troubles arise later on, the documentation can be referred to in order to correct the problem more quickly. Moreover, it enables teammates or supervisors to understand the setup without having to ask a lot of questions.

In this activity I found out how to use basic Linux commands in order to check the server's operating system, its CPU, the amount of RAM and the storage. I also learned how to write clear notes using Markdown, and that AWS, Azure and Google Cloud give different names to services which carry out the same function.

Since completing this mission my GitHub portfolio has improved and now includes another full laboratory folder containing actual notes, screenshots, and a diagram, which shows that I am able to carry out the technical work and explain it clearly.
