# Microsoft Azure

## Brief Overview

Microsoft Azure is a cloud computing platform developed by Microsoft. It was first launched in 2010. Azure is closely integrated with Microsoft products such as Windows Server, Active Directory, and Microsoft 365. Because of this, it is a good choice for organizations that already use Microsoft products and services.

## Global Infrastructure

Azure's global infrastructure is organized into **Regions**. These are geographic areas that contain multiple data centers with redundant power, cooling, and networking systems.
Azure has many regions around the world. It also uses **region pairs** within the same geography. Region pairs help improve availability because planned maintenance is not normally performed on both paired regions at the same time.

## Cloud Management Console

Azure resources can mainly be managed through the **Azure Portal**. It is a web-based management interface that allows users to create, monitor, and manage cloud resources.
Azure also provides the **Azure CLI** and **PowerShell**. These tools can be used to automate tasks and manage Azure resources using commands.

## Four Core Services

1. **Azure Virtual Machines**  
   Provides virtual computers that can be used to run applications and workloads.

2. **Azure Blob Storage**  
   Provides object storage for files, images, videos, documents, backups, and other data.

3. **Azure Active Directory (Entra ID)**  
   Provides identity and access management for users, applications, and resources.

4. **Azure SQL Database**  
   Provides a managed relational database service that helps organizations store and manage structured data.

## Three Advantages

1. **Strong Microsoft Integration**  
   Azure works closely with Windows Server, Active Directory, and Microsoft 365, making it convenient for organizations that already use Microsoft products.

2. **Strong Hybrid Cloud Support**  
   Azure provides tools such as Azure Arc and Azure Stack that help organizations manage resources across on-premises and cloud environments.

3. **Enterprise and Government Support**  
   Azure is commonly used by enterprises and government organizations because it provides security, compliance, and management features for different types of workloads.

## Typical Enterprise Use Cases

Azure can be used for many business and organizational purposes, including:

- Migrating existing Windows Server infrastructure
- Managing Active Directory environments
- Hybrid cloud deployments
- Integrating Microsoft 365 services
- Hosting business applications
- Managing enterprise databases and data
