# Cloud Platform Recommendation Challenge

## Client A - Startup Company

### Recommended Platform: AWS

AWS is a good choice for the startup because it offers many cloud services that can support a growing application. It can help the company start with the resources it needs and increase them as the number of users grows. AWS also has services that can support application development, storage, and databases.

### Possible Services

- Amazon EC2
- Amazon S3
- Amazon RDS

## Client B - University

### Recommended Platform: Microsoft Azure

Azure is the best choice for the university because it already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with these Microsoft technologies, which can make the migration easier. It can also help the university manage users, applications, and cloud resources.

### Possible Services

- Azure Virtual Machines
- Azure SQL Database
- Microsoft Entra ID

## Client C - AI Research Company

### Recommended Platform: Google Cloud Platform (GCP)

GCP is a suitable choice for the AI research company because it has strong tools for Artificial Intelligence and Machine Learning. It also provides services that can support high-performance computing and data processing. GCP can help the company develop, train, and manage AI and ML applications.

### Possible Services

- Compute Engine
- Vertex AI
- BigQuery


## Client D - Global E-Commerce Company

### Recommended Platform: AWS

AWS is a good choice for the global e-commerce company because it has a large global infrastructure. It can support applications that need high availability and can scale when there are more customers. AWS also provides services for computing, storage, databases, and networking.

### Possible Services

- Amazon EC2
- Amazon S3
- Amazon RDS
