# AWS (Amazon Web Services)

## Brief Overview

Amazon Web Services (AWS) was launched in 2006. It is one of the most widely used public cloud service providers. AWS provides different cloud services such as computing, storage, and databases. It uses a pay-as-you-go system, which means users only pay for the resources they use.

## Global Infrastructure

AWS organizes its data centers into **Regions**. Each Region is a separate geographic area that contains at least three physically separated **Availability Zones**. Each Availability Zone has its own power, cooling, and security systems.

The Availability Zones are connected through high-speed and low-latency networks. This setup helps applications continue working even if one Availability Zone experiences a problem or outage.

AWS also provides **Edge Locations**, **Local Zones**, and **Wavelength Zones**. These services help provide faster access to applications and data by placing resources closer to users.

## Cloud Management Console

AWS resources can mainly be managed through the **AWS Management Console**. It is a web-based dashboard that allows users to create, monitor, and manage cloud resources.

AWS also provides the **AWS Command Line Interface (CLI)** and **Software Development Kits (SDKs)**. These tools allow users and developers to manage AWS services using commands and programming languages.

## Four Core Services

1. **EC2 (Elastic Compute Cloud)**  
   Provides virtual servers that can be used to run applications and other workloads.

2. **S3 (Simple Storage Service)**  
   Provides object storage for files, documents, images, videos, backups, and other types of data.

3. **RDS (Relational Database Service)**  
   Provides managed relational databases, making it easier to create, operate, and maintain databases.

4. **IAM (Identity and Access Management)**  
   Controls user access and permissions for AWS resources and services.

## Three Advantages

1. **Large Market Share and Wide Service Catalog**  
   AWS has a large presence in the cloud computing industry and offers many different services.

2. **Mature Global Infrastructure**  
   AWS has a large network of Regions, Availability Zones, and other infrastructure around the world.

3. **Strong Enterprise and Startup Support**  
   AWS supports businesses of different sizes and has many third-party tools and services that can work with its platform.

## Typical Enterprise Use Cases

AWS can be used for many business and organizational purposes, including:

- Large-scale web hosting
- Big data analytics
- Disaster recovery
- Media storage and streaming
- Application development
- Startups that need to increase or decrease resources based on demand
