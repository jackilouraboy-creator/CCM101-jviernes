# Google Cloud Platform (GCP)

## Brief Overview

Google Cloud Platform (GCP) is a public cloud computing platform developed by Google. It uses the same global infrastructure that supports major Google services such as Google Search and YouTube.
GCP provides many cloud services for computing, storage, databases, networking, data analytics, and artificial intelligence. It is especially known for its strong capabilities in **data analytics, artificial intelligence and machine learning (AI/ML), and container technologies**.
GCP is also well known for **Kubernetes**, a system used to manage and run applications inside containers. Kubernetes was originally developed at Google and later became an open-source project.

## Global Infrastructure

GCP has a global infrastructure made up of **Regions and Zones**. A region is a specific geographic location where Google operates cloud resources. Each region contains multiple zones.
The zones within a region are designed to provide redundancy and help improve the availability of applications. This means that if a problem affects one zone, applications can potentially use resources in another zone.
GCP regions and zones are connected through Google's private global network. This network provides high-bandwidth and low-latency connections between different locations. It helps businesses transfer data and operate applications across different geographic areas.
Google continues to expand its cloud infrastructure to provide services to users in different parts of the world.

## Cloud Management Console

GCP resources can mainly be managed through the **Google Cloud Console**. It is a web-based dashboard where users can create, configure, monitor, and manage cloud resources.
GCP also provides the **gcloud command line tool**. It allows users and developers to manage Google Cloud services using commands. This is useful for automation and for users who prefer working through a command-line interface.

## Four Core Services

1. **Compute Engine**  
   Provides virtual machines that allow users to run applications and workloads in the cloud.

2. **Cloud Storage**  
   Provides object storage for different types of data, including documents, images, videos, backups, and application files.

3. **Google Kubernetes Engine (GKE)**  
   Provides a managed environment for running and managing applications using Kubernetes containers.

4. **BigQuery**  
   Provides a cloud-based data warehouse that allows organizations to store, process, and analyze large amounts of data.

## Three Advantages

1. **Strong AI and Machine Learning Tools**  
   GCP provides different tools and services for artificial intelligence and machine learning. These include services for building, training, and deploying AI and ML applications.

2. **Strong Kubernetes Support**  
   Google Kubernetes Engine (GKE) provides managed Kubernetes services. Since Kubernetes originated at Google, GCP has strong support for container-based and Kubernetes-based applications.

3. **Competitive Pricing**  
   GCP offers different pricing options that can help organizations control cloud costs. It also provides sustained-use discounts for certain workloads that use resources for a significant portion of a month.

## Typical Enterprise Use Cases

GCP can be used for many business and organizational purposes, including:

- Data analytics and business intelligence
- Artificial intelligence and machine learning applications
- Big data processing
- Container-based applications
- Kubernetes-native applications
- Application development and testing
- Large-scale data storage
- Websites and cloud-based applications
- Global applications that require reliable network performance
