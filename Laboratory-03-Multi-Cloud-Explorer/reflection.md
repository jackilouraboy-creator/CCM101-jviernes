# Checkpoint 8 - Mission Reflection

After finishing this mission, I learned more about AWS, Microsoft Azure, and Google Cloud Platform. Each one is different, but they all help businesses use cloud computing in their own way.
The platform that impressed me the most was AWS. I liked it because it has a lot of services for computing, storage, databases, networking, and other cloud needs. It has been around since 2006, so it feels more established and trusted by many companies.

AWS, Azure, and GCP are similar because they all offer virtual machines, storage, databases, networking, and identity management. They also all have data centers around the world so businesses can use their services in different locations. In the end, all three platforms are trying to do the same thing, which is to give companies computing power without needing their own physical servers.

The platform a business picks depends on what that business actually needs. For example, a company that already uses Microsoft products might choose Azure because it works well with Windows Server, Active Directory, and Microsoft 365. A company that focuses on AI might choose GCP instead because of tools like Vertex AI. Things like budget, company size, and goals all affect which cloud platform is the best choice.

Acting as a Cloud Solutions Consultant taught me that picking a cloud platform is not just about choosing the most popular one. A consultant needs to understand what the client needs first, then match those needs with the right services. This activity helped me practice making decisions based on business needs instead of just personal opinion.

My GitHub Cloud Computing Portfolio also improved because I added more research and documentation about cloud platforms, and learned how to organize information using Markdown.
